## 需求概述
- 需求ID：1000002
- 需求名称：【PC后台】账户列表-系统配置：增加"入库打码"功能
- 设计依据：根据需求原文设计结构化测试用例

## 生成日期
- 2023年11月7日

## 变更点说明
| 变更编号 | 涉及位置 | 变更内容 | 说明 |
| --- | --- | --- | --- |
| ① | "库存管理"分组位置 | 新增"库存管理"分组 |  |
| ② | "入库打码"配置项 | 新增配置项卡片 |  |
| ③ | 配置弹窗 | 新增配置弹窗及内容 |  |
| ④ | 保存校验 | 校验租户库存批次功能 |  |
| ⑤ | 默认值规则 | 新创建租户默认关闭，老租户升级后设置为关闭 |  |
| ⑥ | 取消操作 | 取消操作不保存修改 |  |
