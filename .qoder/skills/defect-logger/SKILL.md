# 缺陷报告生成 Skill

## 使用方式

用户提供缺陷信息（标题、前置条件、复现步骤、实际结果、预期结果、附件/截图等），
本 Skill 按统一模板生成缺陷报告文件。

若用户只描述了缺陷现象，需先按标题命名规范补全标题，并整理出完整字段后再生成；
缺失的字段（如附件/截图、补充说明）保留字段名占位，不编造内容。

## 缺陷报告模板

⚠️ 严格按以下结构组织缺陷报告（与技能目录内 AI缺陷模版.md 对齐）：

- 文件首行：缺陷标题（纯文本，不加"缺陷标题："标签）
- 分隔线 `---`
- `前置条件：`（触发该缺陷需要满足的前置条件）
- `---`
- `复现步骤：`（编号步骤）
- `---`
- `实际结果：`（执行步骤后实际出现的错误表现）
- `---`
- `预期结果：`（按需求或设计期望的正确结果）
- `---`
- `附件/截图：`（错误截图、日志、抓包数据等）
- `---`
- `补充说明：`（是否阻塞、是否偶发、影响范围等）

示例：

```
【PC后台】配送-司机管理-批量操作-装车时允许加单开启后注释文案缺少"新"字

---

前置条件：
（描述触发该缺陷需要满足的前置条件，例如：用户已登录、购物车已有商品等）

---

复现步骤：
1. 步骤一
2. 步骤二
3. 步骤三

---

实际结果：
（描述执行上述步骤后实际出现的错误表现）

---

预期结果：
（描述按照需求或设计，期望的正确结果）

---

附件/截图：
（可附上错误截图、日志文件、抓包数据等，帮助快速定位）

---

补充说明：
（例如：是否阻塞其他功能、是否偶发、是否影响特定设备/浏览器等）
```

## 标题命名规范

- 统一采用「【端标识】模块-子模块-具体问题描述」三级结构化格式
- PC后台示例：【PC后台】库存-常规分拣-进入分拣页面少调取了接口，导致列表数据一直处于加载状态
- 端标识按缺陷所属端书写（如【PC后台】），模块与子模块之间用 `-` 分隔，最后描述具体问题

## 文件命名规则

- 文件名直接使用缺陷标题作为文件名
- 去除标点符号（如！？。，；："'、等）和特殊字符（如@#$%^&*等），保留核心关键词
- ⚠️ 强制保留【】括号及其内容，不删除、不替换、不转义方括号
- 文件内第一行保留缺陷标题内容（不加"缺陷标题："标签）

## 内容格式规范

- 纯文本格式：无 HTML span 样式标签、无 Markdown `#` 标题标记
- 字段标签（如"前置条件："）直接书写，与模板严格对齐
- 字段之间以 `---` 分隔
- 文件编码 UTF-8

## 文件存储路径

- 默认：`workspace/bugs/{迭代}/{测试人员}/{缺陷标题}.md`
- 目录按迭代版本组织，如 s92 版本为 `workspace/bugs/s92/{测试人员}`（路径模板见配置 `archive.bug_dir`，测试人员子目录名向用户确认）
- 用户未指定版本/人员时，按当前迭代版本与对应测试人员目录处理，不确定时向用户确认

## 多缺陷排序规则

- 同一文件含多个缺陷时，按生成时间正序排列：先产生的缺陷在上方，最新缺陷在文件底部
- 追加新缺陷时，追加到文件末尾，不插入已有缺陷之间

## 执行流程

### 第一步：确认缺陷信息
- 收集：缺陷标题、前置条件、复现步骤、实际结果、预期结果、附件/截图、补充说明
- 标题不符合命名规范时先按规范修正
- 信息不全时：非核心字段留占位；核心字段（标题、复现步骤、实际结果、预期结果）缺失时向用户询问

### 第二步：确定目标文件
- 检查存储目录下是否已存在同名缺陷文件
- 已存在 → 在文件末尾追加新缺陷（时间正序）
- 不存在 → 新建文件

### 第三步：生成文件
- 用 Write 工具创建新文件（避免 SearchReplace 编辑中文标题文件导致 UTF-8 乱码）
- 严格按模板结构生成，纯文本格式

### 第四步：验证
- Read 回读文件，确认：首行为标题（无标签）、无样式标签、中文无乱码、【】括号保留

## 关键坑点

| 坑点 | 影响 | 规避 |
| :--- | :--- | :--- |
| 用 SearchReplace 编辑中文标题文件 | 产生 UTF-8 乱码（如"陷标题"） | 优先用 Write 创建；必须修改时先 Read 验证编码 |
| 文件名去除【】括号 | 缺陷端标识丢失，不符合命名规范 | 只去标点/特殊字符，强制保留【】及其内容 |
| 使用 HTML span 样式标签 | 渲染异常（如黑底背景） | 纯文本格式，字段标签直接书写 |
| 新缺陷插入已有缺陷之间 | 打乱时间正序排列 | 一律追加到文件末尾 |
| 文件首行加"缺陷标题："标签 | 与模板不一致 | 首行直接写标题，不加标签 |
| 标题缺少模块层级 | 缺陷定位困难 | 按【端标识】模块-子模块-问题描述三级格式 |
